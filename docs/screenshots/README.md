# 运行截图清单

把下面 4 张图放进本目录（文件名必须一致），README 的「界面截图」小节即可直接引用。

| 文件名 | 内容 | 怎么截 |
| --- | --- | --- |
| `home.png` | 首页图书列表：分类切换、搜索框、卡片列表 | 编译后首页，滚到能看到 4 张以上卡片的位置 |
| `detail.png` | 图书详情：书目信息、标签、分段简介 | 随便点进一本有简介的图书 |
| `admin-books.png` | 后台图书列表：分页、搜索、上下架开关 | 「我的 → 图书管理」 |
| `admin-edit.png` | 图书编辑页：完整书目字段 + 封面上传 | 「图书管理 → 新增图书」，填完字段再截 |

用模拟器截图即可，尺寸选 750×1334 或开发工具默认机型。
图上如果出现 openid、手机号等信息先抹掉。

图片放好后，在 README.md 里补上引用：

```markdown
| 首页 | 图书详情 |
| --- | --- |
| ![首页](docs/screenshots/home.png) | ![图书详情](docs/screenshots/detail.png) |
```
