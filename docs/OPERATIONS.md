# 运维手册

适用于校园图书管理系统（图书、分类、用户与系统设置）。

## 一、日常维护

### 图书维护

1. 进入「我的 → 图书管理」。
2. 搜索框支持书名、作者、ISBN；分类标签可快速筛选。
3. 列表右侧开关直接上下架，无需进入编辑页。
4. 「新增图书」填写书名、分类、定价后即可保存；作者、出版社、ISBN、出版年、页数、馆藏位置为选填。
5. 「复制」用于快速创建相似图书，副本封面会复制为独立文件，修改原书封面不会影响副本。

### 封面维护

- 建议使用 3:4 竖版封面，单张不超过 10MB；系统会对超过 300KB 的图片自动压缩。
- 封面存放在云存储 `book-covers/年月/` 目录。
- 更换封面后旧文件会自动删除；删除图书时封面一并删除。
- 未上传封面时显示 emoji 图标，可在编辑页「封面图标」中修改。
- 如果封面显示空白，先确认云存储权限为「所有用户可读，仅创建者可读写」。

### 图书介绍

- 「一句话简介」≤200 字，显示在首页卡片。
- 「详细介绍」≤2000 字，显示在详情页，支持换行分段。
- 列表接口不返回详细介绍，编辑页通过单本查询加载，避免列表变慢。

### 分类维护

- 分类名称 ≤12 字，排序值越小越靠前。
- 分类下仍有图书时不能删除；请先把图书改到其他分类或删除图书。
- 停用分类会同时隐藏该分类下的图书，但不会删除数据。

### 用户与权限

1. 成员先打开小程序并进入「我的」，系统才会创建账号。
2. 管理员在「权限管理」中把成员设为管理员。
3. 系统会阻止把最后一名管理员降级。
4. 管理员权限校验缓存 60 秒，刚完成授权后如界面未刷新，重新进入页面或等待一分钟后重试。

## 二、数据备份

1. 云开发控制台 → 数据库 → 选择集合 → 导出。
2. 建议每周导出一次 `books`、`categories`、`users`、`settings`。
3. 云存储中的封面文件不在数据库导出范围内，如需完整备份，使用控制台的存储文件列表另行下载。
4. 备份包含用户 OpenID 与昵称，应存放在加密存储中，不应公开分享。

## 三、性能监控

重点观察云函数 `api` 的以下指标：

| 指标 | 关注点 |
| --- | --- |
| `getMenu` 平均耗时 | 首页列表；若持续上升，检查索引是否缺失 |
| `getMenu` 出流量 | 单次响应应保持在几十 KB 量级 |
| `listBooks` 平均耗时 | 后台列表；关注关键字搜索（正则匹配）耗时 |
| 错误率 | 重点看 `DATABASE_COLLECTION_NOT_EXIST`、索引缺失、存储权限错误 |

建议每月检查一次云存储用量，确认没有异常增长的孤儿文件。

## 四、常见问题排查

### 首页图书为空

1. `categories` 是否有未删除且启用的分类。
2. `books` 中图书的 `enabled` 是否为 `true`、`deleted` 是否为 `false`。
3. 图书的 `categoryId` 是否指向一个启用且未删除的分类。
4. 是否处于关键字或分类筛选状态。

### 保存图书提示「分类不存在或已删除」

分类在编辑期间被删除或停用。返回列表刷新后重新选择分类。

### 图书列表显示「未分类」

图书的 `categoryId` 找不到对应分类，通常是数据导入残留或分类被删除。编辑该图书重新选择分类即可。

### 封面上传失败

1. 云存储是否开通、权限是否正确。
2. 图片是否超过 10MB。
3. 云开发环境是否与小程序一致。
4. 云函数是否已重新部署（旧版本不含新接口）。

### 修改后前台未更新

下拉刷新首页；若仍无变化，确认图书已上架且分类已启用。

### 提示「不支持的操作」

云函数版本落后。重新部署 `cloudfunctions/api`。

## 五、安全建议

- 数据库集合权限保持「所有用户不可读写」，只通过云函数访问。
- `ADMIN_SETUP_TOKEN` 使用随机长字符串，绑定首位管理员后不要外传。
- 定期检查 `users` 集合，及时取消离职成员的管理员权限。
- 不要把数据库导出文件、云环境 ID 与令牌发送到公开群聊或代码仓库。
- 写接口已做服务端鉴权，并按「用户 + 操作」限流（默认 30 次/分钟，绑定管理员收紧到 5 次/分钟）。
  该限流只在单云函数实例内生效，用于抑制误触与脚本刷接口；对外大规模开放仍需网关层配额。
- 封面 fileID 由客户端直传后回传，云函数会复核其位于 `book-covers/` 目录下，避免写入任意云存储路径。

## 六、后续可扩展方向

- 借阅记录与到期提醒（需要新增 `borrows` 集合与定时触发器）。
- 图书封面的缩略图版本，进一步降低列表流量。
- 操作审计日志增加前后差异对比（当前只记录动作与对象）。
- 前台列表改用游标分页，彻底摆脱 skip 深翻页的开销。
- 批量导入（Excel/CSV）与批量上下架。
