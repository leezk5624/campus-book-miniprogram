# 校园图书管理系统
![ci](https://github.com/leezk5624/campus-book-miniprogram/actions/workflows/ci.yml/badge.svg)

一套基于微信云开发（小程序 + 云函数 + 云数据库）的图书信息管理小程序，包含图书浏览端、管理端和云函数后端。

## 已实现功能

### 用户端（只读浏览）
- 按分类浏览图书、关键词搜索（书名/作者/ISBN）、分页加载、图书详情页
- 展示封面、作者、出版社、ISBN、出版年、页数、馆藏位置、标签、定价与借阅次数
- 封面支持云存储图片，未上传时回退为 emoji 图标

### 管理端
- 图书新增、复制、编辑、上下架、删除，支持封面上传与自动压缩
- 支持书名、作者、出版社、ISBN、出版年、页数、馆藏位置、标签、一句话简介与详细介绍
- 图书列表服务端分页、搜索、分类筛选、快速上下架
- 分类新增、重命名、删除、排序
- 图书馆名称、公告、地址、电话、开放时间设置
- 管理员初始化、权限管理，云函数统一鉴权
- 管理员操作日志，列表只返回脱敏标识
- 部署状态自检与前台可见性逐级排查

### 设计要点
- 数据只能经云函数访问，集合权限设为「所有用户不可读写」
- 列表接口字段投影 + 分页，避免长简介进入列表响应
- 写接口统一鉴权；管理认领与分类删除走数据库事务，防止并发产生脏数据
- 用户列表只返回脱敏标识，不向前端下发明文 openid
- 支持本地演示数据（dataMode = mock），便于离线预览
- 单元测试 + 端到端冒烟脚本，并通过 GitHub Actions 在每次推送时校验
- 云函数用内存版 wx-server-sdk 做集成测试，覆盖模块拼装、权限边界与分页语义
- 前台列表用「多取一条」判断是否还有下一页，省掉每页一次的全表 count
- 部署、数据模型与运维见 [DEPLOY.md](DEPLOY.md) 和 docs/

## 部署方法

正式上线请阅读根目录的 [DEPLOY.md](DEPLOY.md)，数据模型见 [docs/DATABASE.md](docs/DATABASE.md)。

本地校验：

```bash
npm run check   # 结构与文件一致性静态检查
npm test        # 单元测试 + 端到端冒烟
```

## 快速预览

1. 使用微信开发者工具导入本目录，AppID 选自己的小程序即可。
2. 项目默认使用云开发（`miniprogram/config/env.js` 中 `dataMode: 'cloud'`）。
3. 先在开发者工具顶部点「云开发」创建环境，把环境 ID 填入 `cloudEnv`，再编译。
4. 如果暂时不想开云环境，可把 `dataMode` 临时改成 `'mock'` 用本地数据预览；此时进入「我的 → 绑定首位管理员」，输入演示令牌 `DEMO8888` 可体验管理端。

## 学生 / 个人主体上线

本项目可以用**个人主体小程序**发布（适合课程作业、毕业设计）：

- 本系统为**图书信息展示与管理工具**，不涉及电商、外卖等经营服务
- 服务类目选工具 / 教育等个人可选类目
- 在 `miniprogram/config/env.js` 中保留 `projectTag`，页面会展示学习项目标识
- 详细信息见 [DEPLOY.md](DEPLOY.md) 的「学生项目 / 个人主体上线说明」

## 目录结构

```text
miniprogram/                 小程序前端
  pages/index/               图书列表
  pages/book/                图书详情
  pages/profile/             我的（按用户/管理员展示不同入口）
  pages/admin/               管理端（图书、分类、设置、权限、状态）
  utils/api.js               统一请求封装
  utils/auth.js              管理员权限守卫
  utils/mock.js              本地演示数据
cloudfunctions/api/          统一业务云函数
  lib/                       按职责拆分的模块（数据库访问 / 图书 / 分类 / 用户 / 审计 / 自检）
tests/unit/                  单元测试（Node.js test runner）
scripts/                     静态检查与端到端冒烟脚本
docs/                        部署与运维文档
```

## 数据说明

- 金额在数据库和小程序中统一使用「分」存储，展示时转换为元。
- 图书封面存储在云存储 `book-covers/` 目录，未上传时显示 emoji 图标。
- 列表接口只返回展示字段，详细介绍与标签由详情接口单独返回。
- 所有写操作都在云函数中校验管理员身份。
